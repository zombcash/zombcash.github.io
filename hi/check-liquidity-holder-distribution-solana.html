1. सही pair खोलें

Verified mint address से DEX Screener पर pair खोजें। Token और quote asset की पुष्टि करें; समान नाम अलग assets हो सकते हैं।

2. Liquidity समझें

Liquidity वह value है जो swaps के लिए pool में उपलब्ध होती है; यह परियोजना का bank balance नहीं है और बदल सकती है। पतले pool में छोटे orders भी कीमत बदल सकते हैं।

3. Exit का अनुमान लगाएँ

Order size की तुलना pool depth से करें और quote में price impact, slippage और fees देखें। छोटे order की कीमत बड़े sale पर मिलना ज़रूरी नहीं।

4. बड़े holders को सावधानी से पढ़ें

Solana Explorer पर mint खोलें। Concentration निकालने से पहले pool, burn, exchange और program accounts पहचानें। हर account अलग व्यक्ति का नहीं होता।

5. Concentration और links देखें

जाँचें कि क्या एक wallet या छोटा समूह pool liquidity से अधिक दबाव डाल सकता है। नए funded wallets संकेत हैं, साझा ownership का प्रमाण नहीं।

6. कई समय बिंदुओं की तुलना करें

Liquidity, बड़े holders का हिस्सा, volume और buys/sells दर्ज करें और फिर जाँचें। अचानक गिरावट पर दोबारा मूल्यांकन करें।

एक काल्पनिक exit test करें

अपने order size की तुलना pool की उपलब्ध depth से करें और वास्तविक swap quote लें। Price impact, slippage और fees देखें। छोटे order sizes पर भी quote दोहराएँ; छोटे order का परिणाम बड़े order पर सीधे लागू नहीं होता। Holder concentration को अलग से जाँचें।

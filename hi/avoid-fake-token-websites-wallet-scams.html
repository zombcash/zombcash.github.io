नकली token websites और wallet scams से कैसे बचें

यदि आप खुद दरवाज़ा खोलते हैं, तो scammers को bunker तोड़ने की ज़रूरत नहीं। Domain और हर signature request सत्यापित करें।

ZOMBCASH सर्वाइवर आर्काइव · 24 अक्टूबर 2026 · शैक्षिक जानकारी, वित्तीय सलाह नहीं।

फील्ड नियम: यह मार्गदर्शिका जोखिम जाँच में मदद करती है; यह किसी टोकन को सुरक्षित प्रमाणित नहीं करती। Seed phrase या private key कभी साझा न करें।

1. Domain स्वतंत्र रूप से सत्यापित करें

किसी link पर केवल इसलिए भरोसा न करें कि वह reply, ad, DM या search result में है। आधिकारिक channel से शुरू करें और domain को अक्षर-दर-अक्षर जाँचें।

2. Recovery words कभी न बताएँ

वास्तविक support agent या token team को seed phrase या private key की ज़रूरत नहीं होती। इन्हें माँगने वाला wallet पर नियंत्रण चाहता है।

3. अनपेक्षित airdrops को संदिग्ध मानें

अनजान tokens, NFTs और reward links bait हो सकते हैं। Embedded sites न खोलें और हटाने के लिए transactions sign न करें। Campaign को official sources से जाँचें।

4. हर wallet prompt पढ़ें

Domain, action, token, amount और permissions जाँचें। जिस transaction को समझ न सकें उसे reject करें। Hardware wallet malicious transaction को सुरक्षित नहीं बनाता।

5. Browsing और treasury अलग रखें

Experiments के लिए अलग wallet रखें और long-term assets अलग रखें। Permissions केवल trusted tools से और सही network जाँचने के बाद revoke करें।

6. यदि click या sign कर दिया

Site से interaction रोकें। Seed phrase या private key उजागर हो सकती है तो wallet को compromised मानें और clean device से assets नए secure wallet में भेजें। Recovery scammers को भुगतान न करें।

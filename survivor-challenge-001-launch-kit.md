## Full challenge description (English)

### SURVIVOR CHALLENGE #001 — ZOMBIE SNAKE

**Objective:** Post your highest score from one run of Zombie Snake during the challenge window.

**Play:** https://zombcash.github.io/arcade.html?game=snake&utm_source=website&utm_medium=owned&utm_campaign=survivor_challenge_001

**Deadline:** Monday, 2 November 2026, 23:59 UTC. Results will be announced on Tuesday, 3 November 2026.

**How to participate**
1. Open ZombieCash Arcade and choose **01 / ZOMBIE SNAKE** (the link above opens the game selection).
2. Press **START / RESTART**, then play with arrow keys or WASD. Collect brains and avoid your tail.
3. After the run ends, capture a screenshot showing the final score.
4. Reply to the official challenge post in the ZombieCash Telegram community with the screenshot before the deadline. If replies are not available, post the screenshot in the community and link that post in your reply.
5. Keep the original screenshot in case moderators ask a short follow-up question.

**Rules**
- One final entry per person.
- No token purchase, payment or wallet connection is required.
- Highest verified score wins. If scores tie, the earliest valid submission wins.
- Moderators manually review screenshots and may ask for a short recording if an entry needs clarification. No automatic screenshot verification is claimed.
- Entries that cannot be reasonably verified may be excluded.
- Only the winner's public handle and verified score will be published.
- **Reward:** community recognition only. No token rewards, Survival Points, cash or other financial rewards are offered.

**Safety:** Never send seed phrases, private keys or wallet credentials. Never pay to participate.

## Organizer checklist
### Before launch
- Open the landing page and game on desktop and mobile; play one test run.
- Check the score stays visible when the run ends and take a test screenshot.
- Verify the official Telegram thread accepts screenshot replies; otherwise specify the group message where participants should post.
- Publish the Telegram launch post first so there is a specific post for X to link to/refer to.
- Use the campaign URL for each source rather than one untagged link.

### During the window
- Post one reminder on Friday, 30 October.
- Save submission links and timestamps to a simple sheet; don't count link clicks as participants.
- If two screenshots tie, ask for additional evidence and apply earliest valid submission as the tie-break.
- Make no changes to the rules after entries begin unless you pause and announce the change.

### On 3 November
- Freeze the entry list at the deadline.
- Review all valid submissions; record public handle, screenshot link, displayed score and submission timestamp.
- Query Arcade leaderboard/registered score where possible as supporting evidence, not as an asserted automatic anti-cheat check.
- Publish the results using actual verified values only.
- Record campaign clicks/sessions separately from unique verified participants.

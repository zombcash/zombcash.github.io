# Homepage visual assets

The homepage visual refresh uses existing project-owned artwork plus Wikimedia Commons image files (not CSS-drawn artwork or embedded base64).

- **Hero / overgrown city:** [Overgrown city, post-apocalyptic](https://commons.wikimedia.org/wiki/File:Overgrown_city,_post-apocalyptic.jpg) — public-domain/CC0 dedication as identified on the file page.
- **Zombie Maker and Living World atmosphere:** [Post-apocalyptic scenery](https://commons.wikimedia.org/wiki/File:Post-apocalyptic_scenery.jpg) — CC0 1.0, originally released by the creator on Pixabay.

The project-owned survivor image fills the sponsor art panel on all nine homepage locales. Wikimedia images are used as decorative backgrounds beneath dark overlays. Text, buttons, cards, and interactive controls remain real HTML and are not baked into the images.

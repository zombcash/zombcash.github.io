# ZombieCash

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

ZombieCash ($ZOMBCASH) is a community-driven meme-coin project with a zombie-apocalypse theme.

- **Website:** https://zombcash.github.io/
- **Zombie Maker:** https://zombcash.github.io/zombie-maker.html
- **Telegram:** https://t.me/ZOMBCASH

## Zombie Maker

Zombie Maker lets visitors upload a photo and request a playful, non-graphic AI zombie portrait in several styles. Image editing is handled by the project's API server, which forwards the image to the Pollinations image-edit endpoint. The server-side Pollinations API key is configured through an environment variable and is not intended to be exposed in browser code.

The page includes image preview, style selection, download and sharing tools, and a local-only recent-creation history.

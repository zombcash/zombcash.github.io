# SURVIVOR CHALLENGE #001 — Zombie Snake

## Challenge configuration
- Format: Game Challenge
- Game: Zombie Snake
- Play: https://zombcash.github.io/arcade.html?game=snake
- Launch date: Tuesday, 27 October 2026
- Deadline: Monday, 2 November 2026, 23:59 UTC
- Results announcement: Tuesday, 3 November 2026, in the ZombieCash Telegram channel and X Community
- Entry: reply in the official Telegram challenge thread with a screenshot showing the final score. If the screenshot cannot be posted in the thread, post it in the community and link the post in your reply.
- Eligibility: one entry per person; no wallet connection or payment required. Do not post private information.
- Verification: the team manually reviews submitted screenshots and may ask for a short screen recording if two entries appear tied or suspicious. No automatic verification is claimed.
- Winner: the highest verified score submitted before the deadline. If scores tie, the earliest valid submission wins. If a score cannot be reasonably verified, it is excluded. The team publishes the winning handle and score, not private information.
- Reward: community recognition only for this first challenge; no token, points, or financial reward.

## Participant instructions (English)
1. Open ZombieCash Arcade and select **01 / ZOMBIE SNAKE**.
2. Press **START / RESTART** and play.
3. When the run ends, capture a screenshot with the final score visible. Use the device screenshot shortcut (Windows: Win+Shift+S; macOS: Shift+Command+4; phone: the usual screenshot buttons).
4. Submit the screenshot as a reply to the official challenge post in Telegram before the deadline.
5. Keep the original screenshot in case the moderators ask a simple follow-up question.

## Operational checklist
- Before launch: open the URL on desktop and mobile, select Zombie Snake, start a run, check that score is visible, and capture a test screenshot. Do not claim the game has been tested unless this manual check is completed.
- During the week: publish one reminder; save each submission link and timestamp; ask for clarification on unclear screenshots.
- After deadline: freeze entries, compare visible scores, resolve ties by timestamp, publish the winner and score, and archive the post.
- If the game or score display is broken, pause the challenge announcement and extend the deadline after the issue is fixed.
